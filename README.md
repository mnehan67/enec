# PolypClean Pathway — 3D website

Open `index.html` in a modern browser while connected to the internet (the page loads Three.js from jsDelivr).

For the most reliable local preview:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## What is modelled
- Self-cleaning inlet mesh: perforated moving belt, rotating drums/pillars, fixed scraper, modular ganging, marker beacon.
- PolypClean robot: AI camera, LEDs, sonar/navigation, four thrusters, robotic removal arm, suction/collection nozzle.
- System pathway and mission loop are based on the uploaded `PolypClean2.pptx` concept.

These are interactive digital concept models, not final manufacturing geometry.
